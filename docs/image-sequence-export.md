# 导出图片序列

在“本地数据集”中打开已完成录制的数据集，点击“导出图片序列”，选择保存位置。
Viewer 自动创建“数据集名-images”目录；已有同名目录时使用新的编号，不覆盖原文件。

| 数据集 | 输出 |
| --- | --- |
| 413GSV0 | cam0–3 的原始 JPEG，每帧一个 .jpg |
| 415RSV0 | cam0–3 的无损 RAW8 PNG |
| 21312V0 | cam0/3 原始 JPEG；cam1/2 的 4096×3072 RAW8 PNG |

JPEG 从容器直接提取，保留原始字节和已有 APP 元数据，不重新编码。
PNG 保存原生 8 位 Bayer 像素，使用灰度容器；不进行去马赛克、缩放、白平衡、
gamma 或亮度调整。因此 PNG 不是 Viewer 预览经过显示处理的彩色截图。

每个 cameraN 文件夹包含图片和 frames.csv。文件名使用相机内序号和原始
微秒时间戳，重复或零时间戳也不会覆盖图片。CSV 记录时间戳、曝光微秒、
增益 gain_x1024、帧号、触发序号、时间模式、前置丢帧数、尺寸、像素格式、
源 Bayer 编码以及源容器字节位置。源索引没有记录的字段留空；常规 413 TUM
索引没有增益、源帧号和时间模式，不能由导出器补造。
源帧头显式记录的零值仍原样保留；曝光或增益为零不表示已测得物理零曝光或零增益。

导出按照各相机原始索引顺序进行，保留不同帧率、缺帧和未知时间戳，不插帧、
不将四路强制配对，也不把设备时间假定为 UTC。export.json 保存设备型号、
已记录的序列号、各相机导出数量和源数据集元数据。

这是相机图片导出功能，不代替现有 ROS Bag 导出。IMU、GNSS、点云等原始数据
仍保留在源数据集中；该功能不会把它们转换为图片或新的 CSV。
21312 混合数据集也支持四路图像预览、时间轴播放、定位和放大；各路保留实际帧率。
此混合格式暂不支持 ROS Bag 导出。

导出可取消。先写入独立临时目录，所有图片及索引完成后才显示为最终输出目录。
读取范围错误、损坏帧或写入失败会报告错误并清理本次临时输出，源数据集保持不变。
正在录制或未完成的数据集不能导出；数据集没有相机图片时会提示原因。
