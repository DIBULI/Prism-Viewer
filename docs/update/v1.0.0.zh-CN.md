# Prism Viewer 1.0.0 更新说明

更新发布日期：2026-09-04

## 兼容关系

- Viewer Release Tag：`v1.0.0`
- Prism SDK：`1.0.0`
- 支持的设备 Agent：`1.0.0`
- 已验证的 sensor-board：`0.4.25`
- USB 协议：`1`

Viewer 1.0.0 固定到与 SDK 和 ROS Adapter 1.0.0 发布版本相同的 Prism SDK
仓库提交。

## Linux SDK 打包更新

- Linux x86-64 在 Ubuntu 20.04、22.04、24.04 和 26.04 上统一使用
  `runtime/ros/linux-x64` 中的同一份 SDK 动态库。
- x86-64 SDK `.so` 采用 Ubuntu 20.04/GCC 9 ABI 基线并静态包含 OpenSSL，
  避免宿主机 OpenSSL 1.1/3.x 依赖冲突。
- Viewer 发布包包含所需 OpenSSL 许可证，并验证 SDK 不依赖动态 `libssl` 或
  `libcrypto`。
- Linux ARM64 继续链接通用 SDK 静态库。
- Release CI 在更新发布版本前，对各受支持 Ubuntu 环境中的 Linux 包进行验证。

设备已经运行 Agent 1.0.0 和 sensor-board 0.4.25 时，不需要更新设备固件。
