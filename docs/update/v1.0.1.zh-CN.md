# Prism Viewer 1.0.1 更新说明

发布日期：2026-09-04

## 兼容关系

- Viewer Release Tag：`v1.0.1`
- Prism SDK：`1.0.0`
- 支持的设备 Agent：`1.0.0`
- 已验证的 sensor-board：`0.4.25`
- USB 协议：`1`

Viewer 1.0.1 直接基于 Viewer 1.0.0，继续使用同一份固定版本的 Prism SDK，
设备固件兼容关系不变。

## 已录制数据集回放

- 本地数据集的帧进度条改为独立占满一行。录制帧之间的曝光值变化时，进度条
  不会再随文字长度变长或变短。
- 新增“跳到帧”控件，可输入从 1 开始的相机帧号并直接跳转。
- 跳帧后，相机、板载 IMU、LiDAR 和 LiDAR IMU 按所选相机帧的时间戳保持
  对齐。
- 自动化界面和数据集测试已覆盖直接跳帧以及曝光文字宽度变化。

## 时间同步状态

- 删除未同步状态中容易误导用户的“等待 GPS/NMEA + PPS”提示。Viewer 1.0.1
  不包含 GPS、GNSS、NMEA 或 RTK 数据功能。

无需更新 Prism SDK、Agent 或 sensor-board 固件。
