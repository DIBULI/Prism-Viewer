# Prism Viewer 1.0.0 update notes

Updated release date: 2026-09-04

## Compatibility

- Viewer release tag: `v1.0.0`
- Prism SDK: `1.0.0`
- Supported device Agent: `1.0.0`
- Qualified sensor-board: `0.4.25`
- USB protocol: `1`

Viewer 1.0.0 pins the exact Prism SDK 1.0.0 repository commit used by the SDK
and ROS Adapter releases.

## Linux SDK packaging update

- Linux x86-64 now uses the single `runtime/ros/linux-x64` SDK shared library
  for Ubuntu 20.04, 22.04, 24.04, and 26.04.
- The x86-64 SDK `.so` uses an Ubuntu 20.04/GCC 9 ABI baseline and statically
  embeds OpenSSL, avoiding an OpenSSL 1.1/3.x host dependency conflict.
- The Viewer package includes the required OpenSSL license and verifies that
  the SDK has no dynamic `libssl` or `libcrypto` dependency.
- Linux ARM64 continues to link the portable SDK static archive.
- Release CI validates packaged Linux builds across the supported Ubuntu
  environments before updating the release.

No device firmware update is required when Agent 1.0.0 and sensor-board 0.4.25
are already installed.
