# Prism Viewer 1.3.0

## 本次同名版本更新

配套本次更新的 SDK / Agent **1.3.0** 和 Sensor Board **0.5.0**。
旧下载文件即使也叫 1.3.0，也不能与新头文件、库混用。
核心 Runtime API 19、Network API 4、Profile API 1 保持不变；新增
CameraControl Runtime API 1。具体 SDK 提交由 Git 子模块和发布流程共同固定。

- 415M 全链路改用原生曝光/增益接口，包括设备打开、空闲暂存、采集中异步修改
  和 Windows 动态库。各路保留手动整数行数和手动增益；自动曝光、自动增益、
  目标亮度、亮度容差及曝光/增益上下限都是全局参数，统一作用于所有相机。
  Web 和 Viewer 采用一致的全局区、四路参数卡片与“刷新 / 应用设置”操作；
  一次提交整套配置。布局沿用 41M3 风格，415M 仍用整数行数与 1/16× 增益步长。
  41M3 保留原曝光/微秒接口，不将旧接口当作新版 415M 的降级路径。
- 配置接受值与逐帧观测值分开显示。请求提交不等于某一帧已经生效；
  异常或超时不盲目重试，不用 STOP/START 绕过，不丢弃或标记过渡帧。
- 完整 RAW12 解码和 CRC 通过后，图像、曝光和时间说明一起更新。
  模式 4 表示设备共同外触发边沿；模式 3 仍是独立诊断事件；模式 0 为未知时间。
  不强行改成相同时间，不把设备时标自动视为 UTC。
- 修复 RAW12 缩略显示的 Bayer/CFA 抽样棋盘格问题。修复只作用于显示路径，
  100% 原始像素、完整 12 位值和录制数据不变；单路缺失不阻塞其他相机和 IMU。
- 合入 1.2.3 的 CORS 账号更新修复：明确连接操作先保存设备账号，再绑定配置代次
  启动模块原生 RTK；校验新鲜状态并确认停止，避免旧账号/旧状态被当成本次连接。
  启动前保留发送实时 GGA 的明确同意，不因打开页面自动连接。
- Wi-Fi/网口使用 Web 登录密码；旧 TLS 配对不恢复。PRISM-NET/4 是明文 TCP，
  仅适用于可信局域网。密码不会写入日志。

## 数据与验证边界

USB 普通预览在 Viewer 端缩略显示；放大和录制保留完整 RAW12。
网页仍只使用设备缩略图，不增加网页 RAW 解码。
录制保留未知时间的原始帧；混合/未知时标数据集按帧序浏览，不伪造播放时间。
RAW12 ROS 导出尚未实现。发布程序不包含 Linux 实机自测启动入口。

发布验证包括四平台构建、离线回归、运行时和包完整性检查；
不等于新增冷启动、Windows USB 或一小时实机长测。此次发布不刷写或操作设备。
