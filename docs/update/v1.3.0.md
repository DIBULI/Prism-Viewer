# Prism Viewer 1.3.0

## 本次同名版本更新

配套本次更新的 SDK / Agent **1.3.0** 和 Sensor Board **0.5.2**。
旧下载文件即使也叫 1.3.0，也不能与新头文件、库混用。
核心 Runtime API 19、Network API 4、Profile API 1 保持不变；新增
CameraControl Runtime API 1。具体 SDK 提交由 Git 子模块和发布流程共同固定。

### 旧设备升级与录制修复

- 使用已发布 SDK 1.3.0 修订 `ac785dfb94fa0838d6f54b7f20ffed14848ea000`，
  缺目 JPEG 帧按本帧有效元数据声明的成员完成组装，不等待未连接的相机。
- 每路独立显示缺目与恢复状态：有效帧明确缺路时立即提示；独立数据流启动或
  上次完整图像后至少 5 秒没有完整图像时显示“相机 N：未收到图像”。
  清除该路旧画面，其他相机和辅助数据继续；新图像到达后自动恢复。
  不将未收到图像直接判为物理故障，不把其他路帧率／帧数填给缺失路。
- 缺目提示依据接收端数据而非缩略图刷新。切页、预览跳帧及迟到的旧解码结果
  不会制造缺目或掩盖提示。此修订通过离线缺目组合／恢复回归，未新增设备实测；
  不修改 Agent 的启动确认路径。

- 未上报型号的旧设备（包括返回 DeviceInfo v3/v4 的 1.2.x Agent）可以打开到
  “仅升级模式”，使用原来的“系统升级”入口。该模式不查询曝光、初始化采集、
  自动操作 Wi-Fi 或写设备时钟；升级完成后重新打开，由新 DeviceInfo 确认型号。
  包完整性、设备忙状态、目标匹配等现有升级器检查不变。不兼容的旧升级协议或
  包格式仍明确拒绝；这不是对所有历史固件完成了升级实测。
- 修复页面切换后的相机预览代次不一致；旧任务结果不会覆盖重新打开页面后的新图像。
- 各型号统一录制实际收到的数据。相机/IMU 缺席不阻止其他流，不要求 UTC 已同步；
  原始时间戳、同步标志和序号保留。415M RAW12 与板载 IMU 使用同一数据集目录，
  附加 LiDAR、GNSS/RTK 流由独立 manifest 记录，互不覆盖文件。
- 板载 IMU 保存原始整数 CSV 和时间戳不变的 SI TUM 文件，有限队列，错误不吞掉；
  收尾执行落盘和逐文件哈希回读。RAW12 继续全解码 CRC 校验；停止后的本地校验
  不再依赖已停止 USB 流的心跳新鲜度，迟到错误不能被成功状态覆盖。
- macOS 原生目录选择框和 Qt 6.11.1 可访问性生命周期修复一起发布；macOS 源码
  构建要求 Qt 6.10+。Windows/Linux 原有运行库支持保持。
- IMU 只显示一个实测速率：优先使用有效 PPS 间的样本数，否则依据连续样本间隔。
  不重采样、不修改记录值，不把主机瞬时收包抖动或配置频率当成实测频率。

新版录制链路已用415M真实数据验证；LiDAR/RTK及其他型号组合目前为离线验证。

- 415M 全链路改用原生曝光/增益接口，包括设备打开、空闲暂存、采集中异步修改
  和 Windows 动态库。各路保留手动整数行数和手动增益；自动曝光、自动增益、
  目标亮度、亮度容差及曝光/增益上下限都是全局参数，统一作用于所有相机。
  Web 和 Viewer 采用一致的全局区、四路参数卡片与“刷新 / 应用设置”操作；
  一次提交整套配置。布局沿用 41M3 风格，415M 仍用整数行数与 1/16× 增益步长。
  41M3 保留原曝光/微秒接口，不将旧接口当作新版 415M 的降级路径。
- 配置接受值与逐帧观测值分开显示。请求提交不等于某一帧已经生效；
  异常或超时不盲目重试，不用 STOP/START 绕过，不丢弃或标记过渡帧。
- 完整 RAW12 解码和 CRC 通过后，图像、曝光和时间说明一起更新。
  模式 4 表示设备共同外触发边沿；模式 3 仍是独立诊断事件；模式 0 为未知时间。
  不强行改成相同时间，不把设备时标自动视为 UTC。
- 修复 RAW12 缩略显示的 Bayer/CFA 抽样棋盘格问题。修复只作用于显示路径，
  完整 12 位值和录制数据不变；单路缺失不阻塞其他相机和 IMU。
- 415M 网格、放大预览、侧边缩略图及回放统一使用标准 sRGB 显示转换，
  包括 100% 像素预览，与 Web 缩略图使用相同曲线。缩略采样和缓存保持线性，
  只在显示副本上转换一次；RAW12 原始值、录制及自动曝光输入不变。
  这是灰度预览的显示转换，不是彩色去马赛克或自动提亮；41M3/JPEG 不重复转换。
- 合入 1.2.3 的 CORS 账号更新修复：明确连接操作先保存设备账号，再绑定配置代次
  启动模块原生 RTK；校验新鲜状态并确认停止，避免旧账号/旧状态被当成本次连接。
  启动前保留发送实时 GGA 的明确同意，不因打开页面自动连接。
- Wi-Fi/网口使用 Web 登录密码；旧 TLS 配对不恢复。PRISM-NET/4 是明文 TCP，
  仅适用于可信局域网。密码不会写入日志。

## 数据与验证边界

USB 普通预览在 Viewer 端缩略显示；放大和录制保留完整 RAW12。
网页仍只使用设备缩略图，不增加网页 RAW 解码。
录制保留未知时间的原始帧；混合/未知时标数据集按帧序浏览，不伪造播放时间。
RAW12 ROS 导出尚未实现。发布程序不包含 Linux 实机自测启动入口。

发布验证包括四平台构建、离线回归、运行时和包完整性检查；
不等于新增冷启动、Windows USB 或一小时实机长测。此次发布不刷写或操作设备。
