# Prism Viewer 1.3.0

## 配套版本

使用本次更新的 Prism SDK 1.3.0、Agent 1.3.0、Sensor Board 0.5.0。
SDK 固定提交为 `f05a914a1153ef08791b939a419510594209f0ee`。
核心 Runtime API 19、Network API 4、Profile API 1；不支持混用旧头文件或旧库。

## 连接与显示

- DeviceInfo 返回设备型号，Viewer 显示并据此选择 41M3、415M、1315 采集路径。
- 网络支持 Wi-Fi 和以太网；认证值与 Web 管理员登录密码相同，仅保存在当前会话。
- 移除旧 TLS 证书配对和独立令牌设置；PRISM-NET/4 为明文 TCP，只用于可信局域网。
- 415M 请求外触发 2 FPS；普通预览由 Viewer 缩略显示，放大和录制保留完整 RAW12。
- 各相机独立预览；单相机缺失不会连带停止其他相机和 IMU。预览替换不等于丢弃落盘数据。
- RAW12 有界录制、长度/CRC 校验、数据集播放；缺口明确报告。尚不支持 RAW12 ROS 导出。
- 移除 Linux 实机自测启动参数，不把自动采集测试包含在用户发布程序中。
  保留离线、合成数据和 UI 回归测试。

## 曝光 API 与行为

41M3 保留原来的 `setExposureConfiguration()`，以及查询、范围和增益接口。
本次不删除旧曝光接口，也不要求 41M3 停止采集后才能调曝光。

415M 手动输入整数积分行数。采集中使用新增的
`beginLiveExposureRows()`、`finishLiveExposureRows()`、
`liveExposureRowsPending()`：只写请求，在正常收帧循环中验证响应。
行数为 3–4096 且受设备报告范围约束，增益固定 1×。
不 STOP/重启、不自动重试、不丢弃或标记过渡帧；确认超时报“尚未确认”，数据流继续。
采集中锁定增益、自动模式、范围编辑和显式刷新，避免进入旧同步控制路径。

核心 SDK 和 ABI 的迁移细节见
[SDK docs/update](https://github.com/DIBULI/Prism-SDK/tree/v1.3.0/docs/update)。

## 验证边界

发布流程验证 Windows x64、macOS arm64、Linux x64/arm64 构建、回归测试和运行时打包。
离线测试不等于设备烧录、物理冷启动、Windows USB 实测或新增一小时连续采集验收。
发布不会访问设备、切换 Wi-Fi、修改设备配置或删除用户录制。
