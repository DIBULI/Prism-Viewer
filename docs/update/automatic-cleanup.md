# 在线更新后的清理

使用带自动清理功能的 Viewer 发起在线更新时，新版窗口启动并确认成功后，更新器删除本次备份中的旧程序文件和空的安装暂存目录。下载包位于系统临时目录，随更新窗口退出清理。

发布包包含程序文件清单。用户后来放入程序目录的数据集、配置和其他个人文件不在清单内，会保留在备份目录。更新器不批量删除历史备份。

新版本启动失败时仍恢复旧版本，不执行清理。文件被占用、清单缺失或异常时，保留无法清理的文件及诊断日志；清理失败不会导致已成功安装的新版本回滚。

第一次从不带该功能的旧 Viewer 更新时，执行的仍是旧更新器，它留下的备份不会自动清除。安装新版后，由新版发起的后续在线更新才会自动清理。
