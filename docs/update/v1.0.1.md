# Prism Viewer 1.0.1 update notes

Release date: 2026-09-04

## Compatibility

- Viewer release tag: `v1.0.1`
- Prism SDK: `1.0.0`
- Supported device Agent: `1.0.0`
- Qualified sensor-board: `0.4.25`
- USB protocol: `1`

Viewer 1.0.1 is based directly on Viewer 1.0.0 and keeps the same pinned Prism
SDK and device-firmware compatibility.

## Recorded dataset playback

- The local-dataset frame progress slider now occupies an independent,
  full-width row. Changing exposure values between recorded frames no longer
  causes the slider to grow or shrink.
- A **Go to frame** control accepts a 1-based camera frame number and jumps
  directly to that frame.
- Direct frame jumps keep camera, onboard-IMU, LiDAR, and LiDAR-IMU playback
  aligned to the selected camera timestamp.
- Automated UI and dataset tests cover frame jumps and exposure-label width
  changes.

## Time-sync status

- Removed the misleading “waiting for GPS/NMEA + PPS” text from the unsynced
  status. Viewer 1.0.1 does not include GPS, GNSS, NMEA, or RTK data handling.

No Prism SDK, Agent, or sensor-board firmware update is required.
