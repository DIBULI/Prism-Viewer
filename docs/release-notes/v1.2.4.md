# Prism Viewer 1.2.4

基于已发布的 **1.2.3**，只增加 RTK 页面轨迹缩放与刻度功能：

- GNSS · GGA 和 RTK · ADRNAV 轨迹支持滚轮、触控板、放大／缩小按钮。
- 可见比例尺自动切换米、厘米、毫米；最大缩放时 1 mm 对应 100 个逻辑像素。
- 2D 拖动平移；3D 拖动旋转，Shift 或右键拖动平移。
- 手动缩放后新数据不会自动缩回；“适应轨迹”或双击恢复自动显示全部轨迹，不清空数据。
- 保留原始定位数据；刻度不代表测量精度。3D 比例尺表示投影长度，不是真实三维距离。

SDK 保持 **1.2.1**，保留 1.2.3 的 CORS 和 PPS 行为；不合入 1.3.0，
不修改采集、录制、设备协议、Agent 或 Sensor Board。

Windows x64、macOS Apple Silicon arm64（13+）、Linux x64/arm64（GLIBC 2.31+）。
macOS 使用 ad-hoc 签名，未经 Apple 公证。构建、离线回归和安装包启动验证不等于实机验收。

## English

Based exactly on v1.2.3. Adds RTK-page trajectory zoom and a meter/centimeter/
millimeter ruler, without changing SDK 1.2.1, CORS, capture, recording or device
protocols. Manual views remain fixed on new data; Fit restores auto-fit without
clearing positions. Display scale is not positioning accuracy. The 3D scale is
projected length, not true 3D distance. No 1.3.0 changes are included.
