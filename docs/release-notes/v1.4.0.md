# Prism Viewer 1.4.0

- 支持 413GSV0、415RSV0、21312V0 数据集图像预览与图片序列导出。
- 雷达实时显示和回放新增可记忆的 Roll／Pitch／Yaw 旋转设置。
- 修复采集时 IMU 数据缺失和相机元数据显示问题，统一采集启停。
- 修复数据集检查误报，保留网络连接与在线更新修复。
- 21312V0两组曝光控制独立，12M增益上限28倍。
- 修复回放闪烁和跳转，简化回放提示与操作。
- 支持 1.3.x 设备单包升级，成功后整机重启一次。
- 在线更新成功启动后自动清理旧程序文件，保留个人数据。
- 修复 21312V0 混合录制，支持 12／24／36 FPS 并保留图像及传感器元数据。
- 修复 21312V0 本地数据集的 IMU 和雷达回放。
- 支持本地 GNSS／RTK 轨迹、定位状态与精度信息回放。
- 新增 MID-360L 采集、回放及待机／唤醒、转速控制支持（实机验证待接入）。
