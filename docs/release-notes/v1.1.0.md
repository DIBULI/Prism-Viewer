# Prism Viewer 1.1.0

使用 Prism SDK **v1.1.0**（`fa9f5fe`，Runtime API 12），要求设备运行 Agent 1.1.0。

## 更新内容

- GPS/GNSS 与 RTK 位置分成两个可滚动的 Tab；显示经纬度、椭球高、本地 ENU 米制坐标、原始/平滑 RTK 位置和相对设备时间的解算历元年龄。
- 使用实时 GNSS/PPS 状态，支持 GNSS UART 波特率配置；设备连接时不自动校时，GPS 授时有效时禁止 Host 校时。
- CORS 自动使用设备 GNSS 生成 GGA，每秒更新；支持 RTCM 2.x/3.x 状态识别，以及 NTRIP `ICY 200 OK` 响应。
- 数据集可录制 GPS/RTK 状态、原始 rover/base RTCM 和时间源变化，保留 Sensor Board 启动时间或 Unix 时间的明确声明。
- Local Datasets 使用 **Camera / IMU / LiDAR** 三个独立 Tab，共享播放控制与时间线；切换不清空 IMU/点云数据。Metadata 按钮展开，不常驻占用显示区域。
- 保留单 IMU 录制、相机曝光信息导出；LiDAR ROS bag 使用标准 PointCloud2，按 10 Hz 聚合并保留每点 `offset_time` 纳秒偏移。
- 增加 SDK 二进制/头文件一致性和分页回放回归测试。

## 平台与安装

- **Linux x64 / arm64**：Ubuntu 20.04、22.04、24.04；发布包在 Ubuntu 20.04 构建，发布前在上述三个版本执行包启动测试。要求 glibc 2.31 或更高。提供 `.tar.gz`，不提供 AppImage。
- **Windows x64**：目标为 Windows 10 1809 或更新版本、Windows 11；CI 在 Windows Server 2022 构建和测试，并非直接在 Windows 10/11 上实测。提供 `.zip`；不提供 Windows ARM64。
- **macOS Apple Silicon**：macOS 13.0 或更新版本，提供 `.zip`。不支持 Intel Mac 或 macOS 12 及更早版本。

包内携带所需 SDK/Qt 及可分发依赖，不是完全静态程序。Linux x64 使用包内共享 SDK，arm64 静态链接 SDK；系统 glibc、内核和显示驱动仍由主机提供。

### macOS 提示“无法验证开发者”

该 App 采用本地签名，尚未进行 Apple 公证。确认下载来源可信后，将 App 拷贝到“应用程序”，在终端运行：

```sh
xattr -dr com.apple.quarantine "/Applications/Prism-Viewer.app"
```

然后重新打开 App。若已有 Viewer 窗口，先退出旧进程再启动更新版。
