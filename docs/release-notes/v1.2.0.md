# Prism Viewer v1.2.0

## 本版本包含的功能

以下汇总 1.2.0 的累计能力，包括此前已有并继续保留的功能。

- USB 设备连接、版本/状态查询、设备配置、Wi-Fi 管理及联合系统升级。
- 四路相机预览与曝光/增益设置、板载 IMU 曲线、MID360/MID360S/XT32 点云显示。
- 数据集录制、分标签回放与验证、ROS1/ROS2 bag 导出，以及中英文界面。
- 单个相机或传感器缺数据时告警并继续采集，显示缺失相机编号。
- 改善显式校时后采集的可靠性。
- 优化 LiDAR 控制与 RTK 页面布局，支持卫星天空图、卫星表和独立 GNSS/RTK 轨迹。
- 支持 RTK-module 状态与控制、统一自动曝光，以及雷达独立待机/唤醒。
- 支持通过 USB 下载 RK 原始数据集，并在电脑上导出 ROS1/ROS2 bag。
- 同步 SDK 与使用文档，补充内部对齐 IMU 和最新曝光行为的说明；这些行为需要配套固件。
- 录制 GNSS/RTK 结果、卫星数、DOP、精度及原始观测/星历和模块 CORS 数据。
- 在定位页面显示接收机提供的北、东、高程标准差；缺失精度不显示为零。
- 支持 MID360S 正常/低速切换，完善状态刷新和错误提示。
- 更新配套 SDK，改善重复启停采集的可靠性。

配合 SDK/Agent **1.2.0** 和对应 **0.4.27** 固件使用。Viewer 安装或文档更新不会自动升级设备。
请同时更新配套 SDK 和设备应用，以使用新增数据与控制功能。

支持 Windows x64、Linux x64/ARM64（glibc 2.31+）、macOS 13+ Apple Silicon。
附件提供安装包和 SHA-256 校验文件。
