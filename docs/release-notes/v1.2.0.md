# Prism Viewer v1.2.0

## 单路数据缺失时继续采集

- 使用匹配 SDK 的部分相机组帧和超时 ACK；显示缺失／损坏的相机编号，继续预览其余相机，不补旧帧。
- 相机、IMU、雷达、GNSS/RTK 单路无数据改为告警，不连带停止其他流。共享 USB 断连、显式停止等仍正常结束会话。
- 录制仅保存实际收到的数据；缺相机或已选择传感器无数据时标记数据集不完整，时间倒退和磁盘错误仍单独报告。
- 保留 SDK Wi-Fi 查询和启停能力；配套新镜像的独立热点服务不再随 Agent 重启而停止。
- 版本保持 1.2.0；请使用同次刷新后的 SDK、Agent 与 Sensor Board 0.4.27 固件。

## SDK 后台升级接口同步

- 更新内置 Prism-SDK 1.2.0，固定到提交 `a35c25fad9f8fc9b8a0c39badd10b0d519502cb5`，重新构建各平台安装包并刷新运行库校验值。
- SDK 新增 `startSensorBoardUpdate()` 和 `sensorBoardUpdateStatus()`，支持匹配 Agent 的后台 Sensor Board 升级与进度查询；保留之前的校时心跳和时间采样修复。
- Viewer 继续使用原有 `upgradeSystem()` 联合 ZIP 升级流程，本次不新增独立 Sensor Board 升级按钮，也不将已有升级流程改为后台任务。
- r10 联合包只更新 Agent 与 BOOT.BIN，不安装 Web、机内升级工具或服务配置；完整安装这些内容需使用对应镜像。
- Viewer 与 SDK 版本保持 1.2.0 / Runtime API 18；不自动连接或升级设备。

## LiDAR 与 RTK 布局修复

- LiDAR 左侧拆分为显示、网络、待机／唤醒三个可滚动子页；待机按钮不再挤压其他控制区。
- 将顶层 GNSS / RTK 图形页合入 RTK，缩短主标签栏；GPS/GNSS、CORS 连接及天空图／轨迹各自使用完整宽度。
- 小窗口下图形区可滚动，不截断天空图和卫星表；保留独立的 GNSS 与 RTK 轨迹。
- 增加中英文、常规／紧凑窗口布局回归；不修改 SDK、设备协议或雷达待机行为。


## 校时后采集异常修复

- 更新内置 Host SDK，修复校时期间心跳线程超时退出，导致随后采集可能自动停止的问题。

## 雷达待机更新

- 增加 MID360/MID360S/XT32 独立硬件状态读取、待机和唤醒按钮，支持中英文。
- 普通采集启停不变；所有采集停止后才可操作，唤醒不会自动采集或录制。

## 功能更新

- 全平台升级到 Prism-SDK v1.2.0 / Runtime API 18，匹配 Agent 1.2.0、Sensor Board 0.4.27。
- 增加 GNSS 卫星天空图、可排序/过滤的卫星表，以及分开展示的 GNSS 与接收机 RTK 轨迹。
- 支持 TimeSync 模式选择、RTK-module 版本和状态显示、错误解释及 LED 状态帮助；时间来源统一为内部/外部授时。
- 增加四相机统一自动曝光与过曝保护，显示实际模拟增益，并保持相机区域宽度稳定。
- 通过当前 USB 连接浏览、下载 RK 本地原始数据集，只导出原始格式；ROS1/ROS2 bag 转换由 Viewer 在电脑上完成。
- 改进录制启动的时间同步检查、分块写入和诊断信息；保留 MID360/MID360S 的逐点 line 信息。
- 支持 XT32 点云显示、录制、回放和 ROS 导出；完善千寻 CORS 预设。
- 使用接收机原生 GNSS/RTK 报文。

## 下载与兼容性

- Windows x64：ZIP，Windows 10 1809+ / Windows 11。
- Linux x64、ARM64：tar.gz，glibc 2.31+，构建基线 Ubuntu 20.04。
- macOS Apple Silicon：ZIP 内含 App，macOS 13+；不提供 Intel Mac 版本。
- 所有安装包包含对应 SDK、Qt 和所需运行库，附件 `SHA256SUMS.txt` 可用于核验下载。

数据集下载需停止设备采集/升级，并使用包含文件传输扩展的新版 Agent 1.2.0。
