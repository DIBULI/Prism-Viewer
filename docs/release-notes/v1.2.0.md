# Prism Viewer v1.2.0

## 功能更新

- 全平台升级到 Prism-SDK v1.2.0 / Runtime API 18，匹配 Agent 1.2.0、Sensor Board 0.4.27。
- 增加 GNSS 卫星天空图、可排序/过滤的卫星表，以及分开展示的 GNSS 与接收机 RTK 轨迹。
- 支持 TimeSync 模式选择、RTK-module 版本和状态显示、错误解释及 LED 状态帮助；时间来源统一为内部/外部授时。
- 增加四相机统一自动曝光与过曝保护，显示实际模拟增益，并保持相机区域宽度稳定。
- 支持从 RK 浏览、下载数据集并导出原始数据或 ROS1/ROS2 bag；默认连接设备 Web 的 80 端口。
- 改进录制启动的时间同步检查、分块写入和诊断信息；保留 MID360/MID360S 的逐点 line 信息。
- 支持 XT32 点云显示、录制、回放和 ROS 导出；完善千寻 CORS 预设。
- 移除旧 Agent raw/smoothed 导航结果接口与旧结果数据集回放，使用接收机原生 GNSS/RTK 报文。

## 下载与兼容性

- Windows x64：ZIP，Windows 10 1809+ / Windows 11。
- Linux x64、ARM64：tar.gz，glibc 2.31+，构建基线 Ubuntu 20.04。
- macOS Apple Silicon：ZIP 内含 App，macOS 13+；不提供 Intel Mac 版本。
- 所有安装包包含对应 SDK、Qt 和所需运行库，附件 `SHA256SUMS.txt` 可用于核验下载。
