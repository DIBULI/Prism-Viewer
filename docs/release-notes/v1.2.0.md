# Prism Viewer 1.2.0 — mainline changes

This file describes the 1.2.0 build configuration; it is not a published tag or
Release. The mainline update does not publish a Release automatically.

- Align all platform packages with Prism SDK 1.2.0 / Runtime ABI 13 and Agent 1.2.0.
- Add receiver GNSS sky/satellite visualization and independent GNSS/RTK trajectories.
- Add RK-local dataset browsing, download and import/export workflow.
- Gate recording on stable internal IMU time, preserve diagnostic metadata,
  and use chunked/segmented dataset writing.
- Show actual per-frame analog gain while keeping camera columns stable and
  letting statistics wrap to their required height.
- Add Qianxun CORS presets and distinguish receiver freshness, PPS and navigation state.
- Preserve Hesai XT32 decoding, timestamp metadata and dataset/ROS export support.
- Extend data-format, GNSS, RK dataset and API compatibility documentation.

Existing `v1.1.1` notes remain a historical release record. This update does not
flash a connected device or claim new XT32 hardware validation.
