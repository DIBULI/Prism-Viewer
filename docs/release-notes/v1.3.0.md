# Prism Viewer 1.3.0

配套最新 SDK 1.3.0（Runtime API 19 / Network API 4 / Profile API 1 / CameraControl API 1）。

- 显示并自动识别设备型号，保留 41M3，接入 415M RAW12/packed12 四路 2 FPS 路径。
- Viewer 内缩略预览，放大和录制使用完整 RAW12；相机独立更新，保留 IMU 数据流。
- Wi-Fi/网口连接均使用 Web 登录密码；移除旧 TLS 配对，不保存网络密码。
- 415M 原生接口支持每路手动整数行数和增益；自动曝光/自动增益、目标亮度/容差和曝光/增益上下限全部为全局设置。采集中异步调整，不暂停、不丢弃或标记过渡帧；41M3 原曝光接口保留。
- 图像与真实共同外触发时间关联更新，未知时间不伪造；配置与逐帧观测值分开。
- 修复 Bayer/CFA 缩略图棋盘格，原始 RAW12 和录制不变。
- 合入 1.2.3 的 CORS 账号保存、模块 RTK 启动和新鲜状态校验修复。
- RAW12 录制、校验及播放；发布程序移除 Linux 专用实机测试入口。
- 保留主分支的 Widgets 绘图实现，不重新引入 Qt Charts。

网络协议为明文 TCP，仅用于可信局域网。RAW12 ROS 导出尚未实现。
跨平台构建/离线回归不代表新增实机长测；本次发布不刷写设备。
