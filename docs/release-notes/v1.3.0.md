# Viewer 1.3.0

- 修复新版录制数据的 ROS Bag 导出。
- 修复最新版本重复提示更新。
- 修复 Windows 在线更新，更新包使用系统临时目录。
- 修复 415RSV0 亮度参数的 RAW8 单位显示与设置。
- 更新 415RSV0 RAW8 预览、录制和回放。

- 统一型号名称，优化相机设置与显示。
- 配套新版 SDK 1.3.0，提供 Windows、macOS、Linux x64 / ARM64 安装包。
