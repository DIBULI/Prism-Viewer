# Prism Viewer 1.3.0

配套最新 SDK 1.3.0（Runtime API 19 / Network API 4 / Profile API 1 / CameraControl API 1）。

本次仍为 **1.3.0**，更新同名下载包，配套设备端 Agent 1.3.0 / Sensor Board 0.5.1。

- 旧设备端 Agent/固件 1.2.x 未上报型号时，允许以“仅升级模式”打开并进入系统升级；不再让采集型号检查阻止升级入口。保留升级包及设备侧校验，不猜测型号启动采集。
- 修复切换相机/IMU 页面后图像不再更新；迟到的旧预览仍被隔离。
- 415M RAW12 录制同时保存板载 IMU 原始字段、原始时间戳及 SI 单位文件，并在结束后完整回读校验。
- 各型号按实际收到的相机、IMU、LiDAR、GNSS/RTK 数据录制，不强制要求四路相机、IMU 或已同步 UTC 全部存在；保留源时间和状态，不补造数据。
- IMU 页面保留一个 Hz 值，优先依据有效 PPS 锚点间样本数计算，不用主机分批收包速度冒充采样频率，也不强制显示 800Hz。
- 修复停止采集后本地录制校验被误判断线，以及收尾错误与成功状态竞争的问题。
- macOS 使用原生录制目录选择框，并更新 Qt 运行库，修复目录关闭及设备列表清理时的可访问性崩溃。

旧设备升级入口不等于所有旧升级器都支持最新包；底层协议或包格式不支持时仍会明确报错，不绕过安全校验。实机验证覆盖415M RAW12+IMU短录制；LiDAR/RTK及其他型号的新增录制组合只完成离线验证，不宣称全部实机通过。

- 显示并自动识别设备型号，保留 41M3，接入 415M RAW12/packed12 四路 2 FPS 路径。
- Viewer 内缩略预览，放大和录制使用完整 RAW12；相机独立更新，保留 IMU 数据流。
- Wi-Fi/网口连接均使用 Web 登录密码；移除旧 TLS 配对，不保存网络密码。
- 415M 原生接口支持每路手动整数行数和增益；自动曝光/自动增益、目标亮度/容差和曝光/增益上下限全部为全局设置。采集中异步调整，不暂停、不丢弃或标记过渡帧；41M3 原曝光接口保留。
- 图像与真实共同外触发时间关联更新，未知时间不伪造；配置与逐帧观测值分开。
- 修复 Bayer/CFA 缩略图棋盘格，原始 RAW12 和录制不变。
- 415M 网格、放大预览及回放统一采用标准 sRGB 显示转换，与 Web 缩略图曲线一致，改善线性 RAW 直接显示偏暗的问题；仅转换显示副本，不改变 RAW12、录制或自动曝光输入，41M3/JPEG 不重复转换。
- 合入 1.2.3 的 CORS 账号保存、模块 RTK 启动和新鲜状态校验修复。
- RAW12 录制、校验及播放；发布程序移除 Linux 专用实机测试入口。
- 保留主分支的 Widgets 绘图实现，不重新引入 Qt Charts。

网络协议为明文 TCP，仅用于可信局域网。RAW12 ROS 导出尚未实现。
跨平台构建/离线回归不代表新增实机长测；本次发布不刷写设备。
