配套 **SDK 1.3.0、Agent 1.3.0、Sensor Board 0.5.2**。

- GNSS / RTK 轨迹新增刻度尺，支持米、厘米、毫米缩放、平移及一键适应轨迹。
- 保留 CORS 账号保存和配置代次校验修复，避免旧账号状态被误报为连接成功。
- 优化 41M3 / 415M 四路组帧和放大预览刷新，取消预览累计告警。
- 保留缺目、传输及录制异常提示。
- 415M 设置界面对齐 41M3，支持全局自动曝光/增益及 sRGB 预览，原始 RAW12 不变。
- 完善相机、IMU 等实际数据的录制与回放，修复切换页面和选择录制目录的问题。
- 支持 USB、网口和 Wi-Fi 连接，网络登录密码与 Web 一致。

下载支持 Windows x64、macOS Apple Silicon、Linux x64 / ARM64。

说明：刻度尺表示显示比例，不代表定位精度；网络连接仅用于可信局域网。新增组帧/缺目改动尚未实机验收，本次未处理 Agent 无相机启动失败问题。
