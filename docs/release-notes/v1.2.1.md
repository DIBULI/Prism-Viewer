# Prism Viewer v1.2.1

本版本基于 v1.2.0，仅修复数据集导出问题，保留 1.2.0 的全部现有功能。

- 修复 GNSS/RTK 未提供卫星数量时，导出 ROS1/ROS2 Bag 报错的问题。
- 保留未定位记录与未知精度，区分“卫星数未知”和“卫星数为零”。
- 补充导出回归测试和使用说明。

配套 SDK 仍为 1.2.0，无需因本次修复升级设备固件。

支持 Windows x64、Linux x64/ARM64（glibc 2.31+）、macOS 13+ Apple Silicon。
附件提供安装包和 SHA-256 校验文件。
